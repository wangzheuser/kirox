存储目录

注册结果输出目录
成功账号以明文 JSON 数组写入该目录下的 accounts.json
Outlook 读取方式
IMAP 兼容旧账号；Microsoft Graph 兼容 OutlookRegister 导出的 ClientID + RefreshToken 数据。
Graph 注册邮箱策略
自动识别别名会优先保留导入邮箱；也可强制使用导入邮箱或 Graph 主邮箱。
代理
代理模式互斥：直连、普通代理、多代理池、Clash 代理四选一。普通代理与代理池均支持 http/https/socks5/socks5h、用户名密码与 {uuid} 会话模板（运行时替换为 32 位无短横线 ID）。
多代理池
启用后将按权重为每个注册任务选择代理；直连、普通代理与 Clash 模式不使用代理池。
邮箱代理
仅用于 Outlook、MoeMail、Mailporary、Cloud-Mail 等邮箱 API；留空=直连。支持 http/https/socks5/socks5h、常见简写与 {uuid}；如需 Clash，可填写 Clash 本地代理地址。
熔断级错误自动停止
开启后遇到 BLOCKED、IP/指纹风控等熔断级错误会立即停止整批任务；关闭后仅记录当前任务失败并继续后续任务。
